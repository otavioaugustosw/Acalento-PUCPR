# Projeto ONG Acalento

Trabalho apresentado como requisito para a disciplina de Experiência Criativa – Projetando Soluções Computacionais, do curso de Bacharelado em Engenharia de Software da PUCPR (2025).

## Sobre o Projeto
Este projeto é um software on-line projetado para simplificar a gestão de estoque e eventos para a ONG Acalento. Seu objetivo principal é centralizar e otimizar as operações da ONG, incluindo o controle de doações e a organização de ações humanitárias, ao mesmo tempo em que facilita a captação de novos doadores e voluntários.

O diferencial do Acalento reside em seu sistema inteligente de gestão de estoque, que permite a distribuição automática de doações entre os diversos assentamentos atendidos pela ONG.

### Personas

O sistema foi desenvolvido para atender três perfis de usuários principais:

* **Administrador:** Responsável pela gestão do sistema, controle de estoque, gerenciamento de eventos e visualização de relatórios.
* **Voluntário:** Pessoa interessada em participar das atividades humanitárias promovidas pela ONG.
* **Doador:** Pessoa física ou jurídica interessada em realizar doações monetárias para apoiar a ONG.

## Funcionalidades Principais

**Para Administradores:**
 
  * **Gestão de Estoque:** Registrar a entrada de itens de doação e gerenciar o estoque geral.
  * **Distribuição Inteligente:** Alocar e distribuir automaticamente os itens do estoque para os assentamentos.
  * **Gestão de Eventos:** Cadastrar novos eventos e atividades.
  * **Controle de Presença:** Controlar a participação de crianças nas atividades.

![acalento4](https://github.com/user-attachments/assets/ee7388ea-9b8d-44c7-9d20-09b047082216)

**Para Voluntários:**

* **Participação:** Acessar e visualizar os eventos disponíveis.
* **Inscrição:** Inscrever-se para participar de novas atividades humanitárias.
* **Histórico:** Visualizar o histórico de eventos que já participou.
* **Cadastro:** Manter seu cadastro de voluntário atualizado.

![acalento2](https://github.com/user-attachments/assets/38fdfcb1-464d-4d2e-87f3-7305af98786d)

**Para Doadores:**

* **Doação:** Realizar doações monetárias para a ONG.
* **Histórico:** Acessar sua área para visualizar o histórico de doações realizadas.
* **Cadastro:** Manter seu cadastro de doador.

## Escopo: O que o projeto NÃO faz

Para manter o foco da solução, as seguintes funcionalidades estão fora do escopo:

* Não é um portal para cadastrar outras ONGs.
* Não gerencia a logística de coleta de doações materiais.
* Não realiza trâmites de declaração de imposto de renda ou emissão de notas fiscais.
* Não é um software de finanças genérico.

## Arquitetura e Modelagem

O projeto foi concebido utilizando artefatos de engenharia de software para garantir um backlog robusto e alinhado às necessidades dos usuários.

* **Visão de Produto:** Definição do público-alvo, benefícios-chave e diferencial competitivo.
* **Canvas PBB:** Mapeamento dos problemas, expectativas, personas e features (Product Backlog Building).
* **User Stories:** Detalhamento das funcionalidades na perspectiva do usuário, com critérios de aceite definidos.
* **Modelo Relacional (DER):** A estrutura do banco de dados foi modelada gerada via MySQL Workbench.
